    📜 提交记录 — 回滚模式说明
    
  
    左键点击日期或 hash 可回滚；右键可修改提交记录
    
  
    查看记录时提示块会跟随当前行；想选中文字时，先按住 Shift 再移入提示块，Shift 期间不会切换到其他行。
    
  
    
    soft
    仅移动 HEAD 指针，代码和暂存区不变
    mixed
    移动 HEAD + 清空暂存区，代码保留
    hard
    ⚠ 彻底还原，未提交的修改全部丢失
  
    

    



    
  
    
    
    ↩️ 回滚到指定版本
    
    
    
    
    
    
    
    
      
    回滚到什么程度？
    
      
    
        
        
    
          
    🟡
    
          
    
            
    soft — 轻撤回（推荐）
    
            
    只撤回 commit 记录，代码和暂存区不变。
    适合：提交后发现消息写错了，或想合并成一次提交。
    
          
    
        
    
        
        
    
          
    🔵
    
          
    
            
    mixed — 清暂存（最常用）
    
            
    撤回 commit 并清空暂存区，代码保留在工作区。
    适合：提交后发现漏了文件，清暂存后重新 add 再提交。默认选项。
    
          
    
        
    
        
        
    
          
    🔴
    
          
    
            
    hard — 硬重置 ⚠️ 慎用
    
            
    彻底回到目标版本，未提交的修改全部丢失。
    除非你确定不要这些修改了，否则不要选这个！
